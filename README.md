# RESET 66

Бесплатное 66-дневное приложение для личного перезапуска и формирования привычек.

## Возможности
- ежедневные задания и отметки выполнения;
- XP, уровни и серия дней;
- настройка привычек (до 12);
- календарь прогресса на 66 дней;
- личный дневник;
- Pomodoro-таймер на 15, 25 и 50 минут;
- локальное сохранение данных в браузере и экспорт резервной копии.

## Запуск
Открой опубликованный GitHub Pages сайт в Safari на iPhone. Чтобы установить его как приложение: **Поделиться → На экран «Домой»**.

Данные сохраняются локально в браузере на устройстве. Очистка данных Safari может удалить историю; используй экспорт резервной копии.

## Развёртывание
GitHub Pages настроен на публикацию через GitHub Actions workflow в `.github/workflows/pages.yml`.
